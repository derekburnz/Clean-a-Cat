# Icon source trial (issue 185)

A sample sheet for Derek's keep or drop: six HUD icons from Phosphor (MIT), Lucide (ISC) and Derek's asset library beside
the icons we draw in `../screens/kit.js`, plus one Kenney UI Pack (CC0) button and panel beside ours. Nothing here is
uploaded to Roblox or used by the game.

- `sheet.png` is the picture; `python3 build.py` rebuilds `sheet.html` from the files below.
- `phosphor/` (core at 2b75f3ad), `lucide/` (at 586bf5c), with their licence files.
- `kenney/` from the GitHub mirror ereborstudios/kenney-ui-pack (at 6ab7fc9, the older 148 file pack; kenney.nl is
  blocked from the build machine), with its licence file. `button_green.png` and `panel_cream.png` are recoloured copies.
- `library/` holds two Cat Cafe icons from Derek's Roblox-Asset-Library.

If Derek keeps a source, the chosen icons are uploaded under the group, checked in the live game and listed in the
credits file. If he drops it, this folder goes.
